🎯 实现的功能

  三个 Baseline 方法：

  ┌─────────────────────────────────────────────────────────────────┐
  │ B01: PCA Single Day                                              │
  │ • 输入：28维特征（序列最后一天）                                    │
  │ • 处理：Scaler → PCA(95%) → L2 normalize                        │
  │ • 检索：Top-15 余弦相似度                                         │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ B02: PCA Summary 20d                                             │
  │ • 输入：196维特征（28维 × 7种统计量）                             │
  │ • 统计量：last, mean, std, min, max, trend, diff_half           │
  │ • 处理：Scaler → PCA(95%) → L2 normalize                        │
  │ • 检索：Top-15 余弦相似度                                         │
  └─────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────┐
  │ B03: Random Neighbor                                             │
  │ • 输入：无特征                                                    │
  │ • 处理：随机选择 15 个邻居                                        │
  │ • 目的：零假设基线（null hypothesis）                             │
  └─────────────────────────────────────────────────────────────────┘
