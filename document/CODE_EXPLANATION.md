# 代码详细说明文档

## 📚 文档目的

本文档配合 `app.py` 中的详细注释，帮助初学者理解整个量化交易策略应用的工作原理。

## 🎯 应用概览

这是一个**量化交易策略分析平台**，主要功能包括：

1. **数据获取**：从 AkShare 下载美股数据
2. **技术分析**：计算 RSI、MACD、EMA、ATR、ADX 等指标
3. **策略开发**：基于多因子评分的量化交易策略
4. **回测验证**：模拟历史交易，评估策略表现
5. **多股对比**：对比分析多只股票的表现和相关性

## 📂 代码结构

### 1. 数据处理模块（第1-150行）

#### 核心函数：
- `standardize_columns()` - 统一不同数据源的列名
- `ensure_date_column()` - 确保有合法的日期列
- `fetch_data()` - 从 AkShare 下载股票数据
- `load_csv()` / `load_uploaded_bytes()` - 加载本地或上传的数据

#### 关键概念：
- **复权**：调整历史价格以反映分红、拆股等公司行为
  - 前复权（qfq）：保持最新价格不变，调整历史价格
  - 后复权（hfq）：保持历史价格不变，调整最新价格

---

### 2. 技术指标计算模块（第150-350行）

#### 核心函数及原理：

##### RSI（相对强弱指标）
```python
compute_rsi(series, period=14)
```
- **作用**：衡量价格上涨和下跌的相对强度
- **取值范围**：0-100
- **交易信号**：
  - RSI > 70：超买（可能下跌）
  - RSI < 30：超卖（可能上涨）

##### MACD（指数平滑异同移动平均线）
```python
compute_macd(series, fast=12, slow=26, signal=9)
```
- **作用**：趋势跟踪，判断买卖时机
- **组成**：
  - MACD 线 = 快速EMA - 慢速EMA
  - 信号线 = MACD 线的 EMA
  - 柱状图 = MACD 线 - 信号线
- **交易信号**：
  - MACD 上穿信号线：金叉（看涨）
  - MACD 下穿信号线：死叉（看跌）

##### ATR（平均真实波幅）
```python
compute_atr(df, period=14)
```
- **作用**：衡量市场波动性
- **用途**：设置止损和止盈位置
- **计算**：真实波幅的指数移动平均

##### ADX（平均趋向指标）
```python
compute_adx(df, period=14)
```
- **作用**：衡量趋势的强度（不是方向！）
- **取值范围**：0-100
- **判断标准**：
  - ADX > 25：有明显趋势
  - ADX < 20：震荡市，无明显趋势

### 3. 策略信号计算模块（第350-550行）

#### 核心函数：`compute_signals()`

这是策略的**大脑**，综合多个因子做出交易决策。

#### 策略逻辑（多因子量化策略）：

##### 📊 因子评分系统
```
因子评分 = 
  + 短期动量 Z 分数 × 权重
  + 长期动量 Z 分数 × 权重
  + MACD 柱状图 Z 分数 × 权重
  + RSI Z 分数 × 权重
  - 波动率 Z 分数 × 权重（注意是负号）
```

**Z 分数原理**：
- Z = (当前值 - 均值) / 标准差
- 用于标准化不同量纲的指标
- Z > 0 表示高于平均，Z < 0 表示低于平均

##### 🔍 过滤条件（必须全部满足）
```
✓ 趋势过滤：快速EMA > 慢速EMA（上升趋势）
✓ 强度过滤：ADX >= 阈值（趋势足够强）
✓ RSI 过滤：RSI 在合理区间内
✓ MACD 过滤：MACD > Signal（趋势向上）
✓ 评分过滤：因子评分 >= 入场阈值
```

##### 📈 仓位管理
```
高评分（分位数 >= 80%）→ 满仓（1.0）
中评分（分位数 >= 60%）→ 半仓（0.5）
低评分                   → 空仓（0.0）
```

##### 🚪 出场条件（任一触发）
```
✗ 因子评分 <= 出场阈值
✗ 快速EMA < 慢速EMA（趋势反转）
✗ RSI 超出合理区间
✗ MACD < Signal（趋势转弱）
```

### 4. 回测模拟模块（第550-750行）

#### 核心函数：`simulate_strategy()`

**回测原理**：用历史数据模拟交易，验证策略的有效性。

#### 回测流程：
```
1. 初始化：设置初始仓位、资金
2. 逐日遍历：
   a. 检查买入信号 → 开仓
   b. 检查卖出信号 → 平仓
   c. 检查止损止盈 → 强制平仓
   d. 记录当日仓位
3. 计算收益：仓位 × 收益率
4. 计算净值：累积收益曲线
```

#### 止损止盈机制：
```
止损价 = 入场价 - ATR × 止损倍数
止盈价 = 入场价 + ATR × 止盈倍数
```

**为什么用 ATR？**
- ATR 反映市场波动性
- 波动大时，止损距离更宽（避免频繁止损）
- 波动小时，止损距离更窄（及时止损）

### 5. 策略评估模块（第750-850行）

#### 关键指标：

##### 最大回撤（Max Drawdown）
```python
max_drawdown(equity)
```
- **定义**：投资组合从峰值下跌的最大幅度
- **公式**：(当前净值 - 历史最高净值) / 历史最高净值
- **意义**：反映策略可能遭受的最大损失
- **经验值**：
  - < 10%：优秀
  - 10-20%：良好
  - 20-30%：可接受
  - > 30%：风险较大

##### 夏普比率（Sharpe Ratio）
```python
sharpe_ratio(returns)
```
- **定义**：每承受一单位风险，能获得多少超额收益
- **公式**：(平均收益 / 收益标准差) × √252
- **意义**：衡量风险调整后的收益
- **经验值**：
  - > 3：优秀
  - 2-3：很好
  - 1-2：较好
  - < 1：一般
  - < 0：亏损

### 6. Walk-Forward 回测模块（第850-1000行）

#### 核心函数：`walk_forward_backtest()`

**Walk-Forward 原理**：
```
时间线：
[---训练窗口---|---测试窗口---|---训练窗口---|---测试窗口---]
 ↑ 优化参数      ↑ 验证表现     ↑ 重新优化     ↑ 再次验证
```

**为什么需要 Walk-Forward？**
- ❌ 传统回测问题：在同一数据上训练和测试 → 过拟合
- ✅ Walk-Forward 优势：训练测试分离 → 更真实

---

### 7. 参数优化模块（第1000-1150行）

#### 核心函数：`random_search_params()`

**随机搜索 vs 网格搜索**：
```
网格搜索：遍历所有参数组合
- 优点：保证找到全局最优
- 缺点：速度慢，组合爆炸

随机搜索：随机采样参数空间
- 优点：速度快，效果不错
- 缺点：可能错过全局最优
```

**优化参数**：
- entry_threshold：入场评分阈值
- exit_threshold：出场评分阈值
- adx_threshold：ADX 强度阈值
- stop_loss_mult：止损倍数
- take_profit_mult：止盈倍数

**优化目标**：
```
目标函数 = 夏普比率 + 总收益
```
平衡收益和风险。

## 🔑 关键概念总结

### 1. 量化交易的基本流程
```
数据获取 → 指标计算 → 信号生成 → 回测验证 → 实盘交易
```

### 2. 技术指标的作用
- **趋势指标**（MACD、EMA）：判断市场方向
- **震荡指标**（RSI）：判断超买超卖
- **波动指标**（ATR）：衡量市场波动
- **强度指标**（ADX）：判断趋势强度

### 3. 多因子策略的优势
- 综合多个信号 → 提高准确率
- 因子互补 → 降低单一指标失效风险
- 权重调整 → 灵活适应不同市场

### 4. 风险管理的重要性
- 止损：控制单次亏损
- 止盈：锁定利润
- 仓位管理：分散风险
- 回撤控制：保护资金
