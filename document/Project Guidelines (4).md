# Project of AIE1902

## 1. Introduction

Students form groups to do a group project. You are free to choose which dataset to use. Your final report will be presented in the form of a webapp. You are required to submit a zip file of a folder that contains all the necessary files for the webapp.

## 2. Project Requirement

### 2.1 Basic Requirements

The project is about financial data analysis. The following basic requirements **must** be demonstrated in your final report:

1. The problem to be solved must be clearly described. A clear answer must be provided at the end of the project.
2. Propose and fully specify the models used in your project.
3. You should understand how your chosen models work, for example their constraints, strengths, and weaknesses.
4. The simple models mentioned in our lecture notes should be implemented to compare with your proposed models whenever possible. The models should be implemented correctly. For example, the conditions for stationarity should be checked before using ARIMA models.
5. Briefly describe how the parameters of the models are learned. Some important parameters should be adjustable in your webapp.
6. Check the models using the methods mentioned in our lecture notes.
7. State and possibly interpret the difference between your proposed models and the other models.
8. State all related references.

A project will get full baseline scores for the final report if all the requirements have been met correctly.

## 3. Defence

Each student needs to answer a set of multiple choice questions about the project. Please check the schedule for the date of the defence.

## 4. Final Report Submission

### 4.1 Submit through a zip file with a HTML file, code files, and other related files

You need to submit **a zip file** containing:

1. A HTML file that can present your report by clicking the file.
2. Related codes.
3. Other related files for running the webapp.

Only one member needs to submit the zip file with a name in the format:

- `Final_gp01.zip`
- `Final_gp02.zip`
- `...`
