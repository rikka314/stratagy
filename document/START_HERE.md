## 🚀 快速使用指南

### 场景 1：本机运行（当前电脑）

**最简单方法**：
1. 双击 `启动应用.command` (macOS/Linux) 或 `启动应用.bat` (Windows)
2. 等待浏览器自动打开
3. 开始使用！

---

### 场景 2：分享给他人（其他电脑）

**步骤**：
1. **打包**：
   ```bash
   # 压缩整个项目文件夹
   zip -r 量化交易策略分析器.zip stratagy/
   ```

2. **分享**：
   - 发送 ZIP 文件给对方
   - 附带说明：解压后双击运行启动脚本

3. **接收者操作**：
   ```
   1. 解压 ZIP 文件
   2. 确保已安装 Python 3.8+
   3. 双击运行启动脚本
   4. 首次运行会自动安装依赖（需要几分钟）
   5. 浏览器自动打开应用
   ```

---

### 场景 3：环境诊断（排查问题）

**出现问题时**：
1. 运行环境检查工具：
   ```bash
   python3 check_environment.py
   ```

2. 查看检查结果：
   - ✅ 绿色勾：通过
   - ❌ 红色叉：需要修复
   - ⚠️ 黄色叹号：警告

3. 根据提示修复问题：
   - Python 版本过低 → 升级 Python
   - 依赖包缺失 → 运行 `pip install -r requirements.txt`
   - 文件缺失 → 重新解压或下载完整文件

4. 修复后重新检查，直到全部通过

## 🎯 部署到其他电脑的关键点

### ✅ 必备条件
1. **Python 3.8+**（推荐 3.10+）
2. **网络连接**（首次安装依赖 + 获取股票数据）
3. **500MB+ 硬盘空间**

### ⚠️ 常见障碍
1. **Python 未安装或版本过低**
   - 解决：从 python.org 下载安装
   
2. **pip 安装慢或失败**
   - 解决：使用国内镜像源
   ```bash
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

3. **防火墙阻止**
   - 解决：允许 Python 和 Streamlit 访问网络
   
4. **端口占用**
   - 解决：更换端口或关闭占用进程
