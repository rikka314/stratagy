## 🚀 快速开始

### 首次使用
1. 运行 `scripts/setup.bat`（Windows）创建虚拟环境并安装依赖
2. 运行 `scripts/start.bat`（Windows）或 `scripts/启动应用.command`（macOS）启动应用

### 日常使用
- Windows：双击 `scripts/start.bat`
- macOS/Linux：双击 `scripts/启动应用.command`
- 或直接命令行：`streamlit run app.py`

## 📝 模块说明

| 模块 | 用途 |
|------|------|
| `app.py` | Streamlit 入口，页面路由和配置 |
| `core/config.py` | 股票列表、默认参数、策略预设等常量 |
| `core/data.py` | AkShare 数据获取、CSV 加载、列标准化 |
| `core/indicators.py` | RSI、MACD、ATR、ADX、布林带等技术指标 |
| `core/signals.py` | 多因子评分、交易信号生成 |
| `core/backtest.py` | 策略回测引擎、步行前进分析 |
| `core/optimizer.py` | 预设评估 + 随机/贝叶斯/遗传算法参数优化 |
| `core/visualization.py` | 多股对比、相关性热力图、风险收益散点等图表 |
| `core/portfolio.py` | 等权/优化权重投资组合回测 |
| `ui/sidebar.py` | 侧边栏：股票选择、参数调节、数据源选择 |
| `ui/multi_stock.py` | 多股票对比分析页面 |
| `ui/single_stock.py` | 单股票深度分析页面 |

## 🗂️ 可以删除的内容

- `.venv/` — 虚拟环境（可通过 `scripts/setup.bat` 重建）
- `__pycache__/` — Python 缓存（自动生成）
- `.DS_Store` — macOS 系统文件
- `app_original.py` — 重构前备份（仅供参考）
