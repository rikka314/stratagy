# 参数优化功能升级文档

## 📋 问题诊断

### 原始问题
用户反馈"自动搜索参数的功能好像失灵"，经过分析发现以下问题：

1. **Phase 1 新因子权重缺失**
   - 在 Phase 1 实现中新增了 5 个技术因子，但这些因子的权重是硬编码的
   - `compute_signals()` 函数中硬编码权重：
     - 布林带位置: 0.8
     - OBV 趋势: 1.0  
     - 成交量比率: 0.6
     - 价格位置: 0.7
     - 回撤惩罚: -0.5
   - 参数搜索功能无法优化这些新因子权重

2. **随机搜索效率低下**
   - 原有方法：完全随机搜索（Random Search）
   - 参数空间从 5 个增加到 10+ 个
   - 随机搜索在高维参数空间中效率极低，需要数百次试验才能找到好参数

3. **缺乏智能优化**
   - 不利用历史试验结果
   - 浪费计算资源在低质量区域

## ✅ 解决方案

### 1. 参数化新因子权重

**修改 `compute_signals()` 函数签名**：
```python
def compute_signals(
    # ... 原有参数 ...
    # 新增：Phase 1 新因子权重参数
    weight_bb: float = 0.8,          # 布林带位置权重
    weight_obv: float = 1.0,         # OBV 趋势权重
    weight_volume: float = 0.6,      # 成交量比率权重
    weight_price: float = 0.7,       # 价格位置权重
    weight_drawdown: float = 0.5,    # 回撤惩罚权重
) -> pd.DataFrame:
```

**修改因子评分计算**：
```python
df["factor_score"] = (
    # 原有因子（Z-score标准化）
    weight_mom_short * df["mom_short_z"]
    + weight_mom_long * df["mom_long_z"]
    + weight_macd * df["macd_z"]
    + weight_rsi * df["rsi_z"]
    - weight_vol * df["vol_z"]
    
    # 新增因子（排名法标准化，可优化权重）
    + weight_bb * (df["bb_position_rank"] - 0.5) * 2
    + weight_obv * (df["obv_trend_rank"] - 0.5) * 2
    + weight_volume * (df["volume_ratio_rank"] - 0.5) * 2
    + weight_price * (df["price_position_rank"] - 0.5) * 2
    - weight_drawdown * (df["drawdown_rank"] - 0.5) * 2
)
```

### 2. 引入贝叶斯优化（Optuna）

**新增依赖**：
```bash
pip install optuna
```

**新增函数 `bayesian_optimize_params()`**：

#### 核心原理

**贝叶斯优化 vs 随机搜索**：

| 特性 | 随机搜索 | 贝叶斯优化 |
|------|---------|-----------|
| 采样策略 | 完全随机，不利用历史 | 智能采样，基于历史构建代理模型 |
| 收敛速度 | 慢，需要大量试验 | 快，50-100 次试验即可 |
| 参数空间 | 低维(< 5 参数) | 高维(10+ 参数) |
| 计算效率 | 低，大量浪费 | 高，集中在有希望区域 |

**工作流程**：
1. 初始化：随机采样几组参数
2. 构建代理模型：用高斯过程拟合 参数→性能 的映射关系
3. 采集函数：平衡探索（Exploration）和利用（Exploitation）
   - 探索：尝试未知区域
   - 利用：在已知高分区域精细搜索
4. 迭代优化：根据新结果更新模型，重复步骤 2-3

**优化的参数**（共 10 个）：

核心参数（5个）：
- `entry_threshold`: 入场评分阈值 [-1.0, 2.0]
- `exit_threshold`: 出场评分阈值 [-2.0, 0.5]
- `adx_threshold`: ADX 强度阈值 [10, 35]
- `stop_loss_mult`: 止损倍数 [0.5, 4.0]
- `take_profit_mult`: 止盈倍数 [1.0, 6.0]

新因子权重（5个）：
- `weight_bb`: 布林带位置权重 [0.0, 2.0]
- `weight_obv`: OBV 趋势权重 [0.0, 2.0]
- `weight_volume`: 成交量比率权重 [0.0, 1.5]
- `weight_price`: 价格位置权重 [0.0, 1.5]
- `weight_drawdown`: 回撤惩罚权重 [0.0, 1.5]

**优化目标**：
```python
score = sharpe_ratio + total_return - abs(max_drawdown) * 0.5
```
- 最大化夏普比率（风险调整后收益）
- 最大化总收益
- 最小化最大回撤（惩罚系数 0.5）

- 随机搜索：稍慢，40-60 秒

### 步骤 3：查看结果

- **综合评分**：夏普 + 收益 - 回撤惩罚

- **夏普比率**：风险调整后收益
- **最大回撤**：最大亏损幅度
- **新因子权重**：自动优化的权重（仅贝叶斯优化）

### 步骤 4：应用参数
如果满意，点击"**应用推荐参数**"：
- 自动更新侧边栏的阈值、止损止盈参数
- 页面自动刷新，使用新参数重新回测

### 步骤 5：验证效果
观察"测试集表现"部分：
- 策略收益 vs 买入持有
- 最大回撤是否改善
- 夏普比率是否提升

## 💡 优化技巧

### 1. 多次优化取最优
- 贝叶斯优化有随机性，可运行 2-3 次
- 选择综合评分最高的结果

### 2. 关注测试集表现
- 训练集评分高 ≠ 测试集表现好
- 警惕过拟合：训练集收益 >> 测试集收益

### 3. Walk-Forward 验证
- 启用 Walk-Forward 回测
- 观察多个时间窗口的稳定性

### 4. 调整优化目标
如果需要更保守的策略，可以：
- 增加回撤惩罚系数（当前 0.5 → 1.0）
- 在代码中修改目标函数

## 🐛 故障排除

### Q1: "需要安装 optuna 库"
```bash
pip install optuna
```
重启 Streamlit 应用。

### Q2: 优化时间过长
- 减少试验次数（60 → 40）
- 减少训练集数据量（train_ratio 0.7 → 0.5）

### Q3: 找到的参数在测试集表现差
- 可能过拟合，尝试：
  - 增加训练集数据
  - 减少试验次数
  - 使用更保守的参数范围

### Q4: 随机搜索仍失效
确认：
- 训练数据足够（> 50 天）
- 指标开关至少启用一个过滤器
- 没有数据异常（NaN、Inf）
