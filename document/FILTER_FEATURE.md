# 指标过滤器功能说明

**更新日期**: 2026年2月4日  
**最新版本**: v2.0 - 添加参数自动折叠功能

## 🎯 新增功能

在"策略参数"部分新增了**可选择的入场过滤指标**功能，用户可以自由选择启用哪些技术指标作为入场和出场的过滤条件。

### ✨ v2.0 更新
- **智能参数折叠**: 未勾选的指标参数会自动折叠，保持界面简洁
- **视觉标识**: 启用的参数用 🔵 蓝色标题，折叠的参数用 🔘 灰色标识
- **默认值保护**: 折叠的参数仍使用默认值进行计算，确保策略正常运行

---

## 📊 功能说明

### 问题背景

原策略要求**5个条件全部满足**才能入场：
1. ✓ 趋势过滤 (EMA 快线 > 慢线)
2. ✓ 强度过滤 (ADX ≥ 阈值)
3. ✓ RSI 过滤 (RSI 在合理区间)
4. ✓ MACD 过滤 (MACD > Signal)
5. ✓ 评分过滤 (因子评分 ≥ 入场阈值)

这导致入场条件**极其严苛**，策略对市场变化**不够灵敏**，可能错过很多交易机会。

### 解决方案

新增**指标选择器**，允许用户：
- 勾选要启用的过滤指标
- 未勾选的指标仍参与因子评分计算，但不作为过滤条件
- 灵活调整策略的严格程度

---

## 🎮 使用方法

### 1. 位置
在侧边栏 → **策略参数（趋势过滤 + MACD/RSI/ATR）** → **🎯 选择使用的入场过滤指标**

### 2. 可选指标

| 指标 | 作用 | 默认状态 | 参数状态 |
|-----|------|---------|---------|
| **✓ 趋势过滤 (EMA)** | 要求快线>慢线（上升趋势）才允许入场 | ✅ 启用 | 🔵 展开显示 |
| **✓ 强度过滤 (ADX)** | 要求ADX≥阈值（趋势强度足够）才允许入场 | ✅ 启用 | 🔵 展开显示 |
| **✓ RSI 过滤** | 要求RSI在设定区间内才允许入场 | ✅ 启用 | 🔵 展开显示 |
| **✓ MACD 过滤** | 要求MACD>信号线才允许入场 | ✅ 启用 | 🔵 展开显示 |

### 3. 参数折叠功能 ⭐ NEW

**当指标被取消勾选时：**
- ✅ 相关参数自动折叠，界面更简洁
- ✅ 折叠的参数仍可点击展开查看/调整
- ✅ 未启用的参数显示警告提示："⚠️ XX过滤未启用，这些参数仅用于指标计算"
- ✅ 参数使用默认值（或展开后的自定义值）

**示例：**
```
勾选 "✓ 趋势过滤 (EMA)"
  ↓
显示：🔵 趋势 EMA 参数
      ├─ 趋势 EMA 快线: [滑块]
      └─ 趋势 EMA 慢线: [滑块]

---

取消勾选 "✓ 趋势过滤 (EMA)"
  ↓
显示：🔘 趋势 EMA 参数（已折叠，点击展开）▼
      （折叠状态，点击可展开）
```

### 4. ATR 止损止盈
**始终显示**，不受过滤器影响，因为止损止盈是风险管理的核心。

### 3. 策略模式推荐

#### 📊 完整策略（4/4 指标启用）
- **特点**: 条件严格，信号稀少但质量高
- **适用**: 保守型投资者，追求高确定性
- **风险**: 可能错过部分机会

#### 📊 平衡策略（2-3/4 指标启用）
- **特点**: 适中的信号频率和质量
- **适用**: 大多数投资者
- **推荐组合**:
  - 趋势 + MACD（趋势跟随）
  - 趋势 + RSI（趋势 + 超买超卖）
  - 强度 + MACD（强趋势跟随）

#### ⚠️ 宽松策略（1/4 指标启用）
- **特点**: 信号频繁，但假信号较多
- **适用**: 激进型投资者，短线交易
- **风险**: 较高，需要严格止损

#### ❌ 无过滤策略（0/4 指标启用）
- **特点**: 仅依赖因子评分
- **风险**: 极高，不推荐使用

## 🔧 技术实现

### 代码改动

#### 1. `compute_signals()` 函数
新增4个布尔参数：
```python
use_trend_filter: bool = True,
use_strength_filter: bool = True,
use_rsi_filter: bool = True,
use_macd_filter: bool = True,
```

#### 2. 动态过滤逻辑
```python
# 入场条件：根据选择动态构建
filter_conditions = []
filter_conditions.append(df["factor_score"] >= entry_threshold)  # 基础条件

if use_trend_filter:
    filter_conditions.append(df["trend_ok"])
if use_strength_filter:
    filter_conditions.append(df["strength_ok"])
if use_rsi_filter:
    filter_conditions.append(df["rsi_ok"])
if use_macd_filter:
    filter_conditions.append(macd_above)

# 合并条件（AND 逻辑）
filter_ok = filter_conditions[0]
for condition in filter_conditions[1:]:
    filter_ok = filter_ok & condition
```

#### 3. 出场条件
同样支持可选指标：
```python
exit_conditions = []
exit_conditions.append(df["factor_score"] <= exit_threshold)  # 基础条件

if use_trend_filter:
    exit_conditions.append(df["ema_fast"] < df["ema_slow"])
if use_rsi_filter:
    exit_conditions.append((df["rsi"] > rsi_upper) | (df["rsi"] < rsi_lower))
if use_macd_filter:
    exit_conditions.append(df["macd"] < df["signal"])

# 合并条件（OR 逻辑，任一触发则出场）
exit_block = exit_conditions[0]
for condition in exit_conditions[1:]:
    exit_block = exit_block | condition
```

## 📈 实验建议

### 对比测试
1. 先用**完整策略**（4/4）回测，记录收益和夏普比率
2. 逐步减少过滤器（3/4, 2/4, 1/4），观察变化
3. 对比不同组合的表现：
   - 总收益率
   - 夏普比率
   - 最大回撤
   - 交易频率

### 优化方向
1. 使用**自动搜索参数**功能，在不同过滤器组合下优化
2. 在**Walk-Forward 回测**中验证稳定性
3. 针对不同股票调整过滤器组合

## ⚠️ 注意事项

1. **过滤器越少，风险越高**
   - 需要更严格的止损止盈设置
   - 需要更小的仓位

2. **因子评分仍然重要**
   - 即使禁用所有过滤器，评分阈值仍然生效
   - 评分是策略的核心，过滤器只是辅助

3. **不同市场环境**
   - 趋势市场：启用趋势+强度过滤器
   - 震荡市场：可以禁用趋势过滤器，保留RSI
   - 强势市场：可以放宽过滤条件

4. **参数搜索**
   - 自动搜索会在当前过滤器配置下优化参数
   - 更换过滤器组合后，建议重新搜索
