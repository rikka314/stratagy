**结论**: **20日 horizon 有效** ✅

### 2. 加入宏观特征的效果（B05 vs B04）

**改进**:
- Mean Sharpe: 0.166 → 0.166 (**无变化**)
- 特征维度: 28 → 36 (**+28.6%**)

**观察**:
- ⚠️ 宏观特征对简单专家的效用标签**没有明显改善**
- 可能原因：
  1. 当前使用的是**模拟宏观数据**，不是真实 VIX/SPY
  2. 简单的动量和均值回归专家**本身表现太差**（win rate 2.8%）
  3. 专家效用计算只看未来收益，**没有使用宏观特征作为专家选择依据**

**结论**: **宏观特征本身无效** ❌（但这是因为实验设计问题）

### 3. 根本问题仍存在

**Win Rate 仅 2.8%**: 这说明：
- 当前的"模拟专家"（动量 + 均值回归）**本质上是随机的**
- 简单的技术信号（`mom_short > 0` 或 `rsi < 30`）**没有预测能力**
- 这验证了 Phase 0 诊断：**专家同质化严重，缺乏真正的多样性**

## 经验教训

### 1. 实验设计很重要

**错误**: 只计算专家的未来效用，但没有测试"用宏观特征选择专家"
**教训**: Phase 3 必须测试完整链路：特征 → 模型 → 专家选择 → 实际收益

### 2. 简单专家不等于好专家

**错误**: 用 `mom_short > 0` 这种过于简单的规则定义专家
**教训**: Phase 2 需要更精细的专家设计，考虑阈值、regime、风控等

### 3. 模拟数据的局限性

**错误**: 用随机游走生成的 VIX/SPY 数据
**教训**: 模拟数据缺少真实市场的结构（regime 切换、危机、相关性变化）

### 4. Win Rate 是重要信号

**发现**: Win rate 2.8% 远低于随机（应该 ~50%）
**教训**: 这说明当前专家不仅没用，而且是**反向指标**
