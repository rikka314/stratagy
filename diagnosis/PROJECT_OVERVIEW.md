# 策略诊断实验 - 项目总览

## 📖 项目背景

当前的量化交易策略表现不佳，甚至不如简单的"买入并持有"策略。我们需要通过系统性的诊断实验，找出问题根源，为后续优化提供数据支持。

## 🎯 核心目标

1. **识别问题**：找出策略表现差的具体原因
2. **评估因子**：测试哪些技术指标真正有效
3. **简化策略**：验证简单策略是否更好
4. **优化参数**：找到最优的参数区间
5. **洞察交易**：分析交易行为的问题

## 🔍 核心问题假设

基于初步分析，我们假设问题可能来自：

1. **过度复杂**：5 个入场条件导致过度保守
2. **技术指标滞后**：RSI、MACD 等总是晚一拍
3. **固定参数**：不适应市场变化
4. **因子冗余**：多个相似因子造成信息重复
5. **止损止盈不当**：ATR 倍数设置问题

## ⚠️ 注意事项

### 数据使用
- 数据时间跨度：1984-2026（约 40 年）
- 训练/测试切分：70/30
- 注意前视偏差（Look-ahead Bias）

### 计算效率
- 数据量较大（9000+ 行），注意计算时间
- 大规模参数扫描使用并行计算
