# 项目结构说明

## 📁 目录结构

```
stratagy/
│
├── 📱 启动应用.bat          # Windows 启动脚本
├── 📱 启动应用.command       # macOS 启动脚本
├── 🔧 一键安装.bat          # Windows 一键安装向导
│
├── 📄 app.py               # 主应用程序
├── 📋 requirements.txt     # Python 依赖列表
├── 🧪 check_environment.py # 环境检查工具
│
├── 📖 README.md           # 项目主文档
├── 📖 START_HERE.md       # 快速开始指南
├── 📋 CHECKLIST.md        # 项目检查清单
│
├── 📊 data/               # 股票数据文件夹
│   ├── aapl_daily.csv
│   ├── googl_daily.csv
│   ├── meta_daily.csv
│   └── ...
│
├── 📚 document/           # 详细文档
│   ├── CODE_EXPLANATION.md
│   ├── DEPLOYMENT.md
│   ├── STRATEGY_IMPROVEMENT.md
│   └── ...
│
└── 🎁 packaging/          # 打包相关文件（可忽略）
    ├── build_exe.py      # PyInstaller 打包脚本
    ├── app.spec          # PyInstaller 配置
    ├── hook-akshare.py   # 自定义 hook
    └── 分发说明.md       # 分发文档

```

## 🚀 快速开始

### 首次使用
1. 双击 `一键安装.bat`（Windows）
2. 等待安装完成

### 日常使用
- 双击 `启动应用.bat`（Windows）
- 或双击 `启动应用.command`（macOS）

## 📝 主要文件说明

| 文件 | 用途 |
|------|------|
| `app.py` | 量化策略分析应用主程序 |
| `requirements.txt` | 项目依赖包列表 |
| `一键安装.bat` | 自动创建虚拟环境并安装依赖 |
| `启动应用.bat` | 启动 Streamlit 应用 |
| `check_environment.py` | 检查运行环境是否正确配置 |

## 🗂️ 可以删除的内容

- `.venv/` - 虚拟环境（可重新生成）
- `__pycache__/` - Python 缓存（自动生成）
- `packaging/` - 打包相关文件（非必需）
- `.DS_Store` - macOS 系统文件（可删除）

## 📦 分享给他人

只需压缩并发送以下内容：
- `app.py`
- `requirements.txt`
- `一键安装.bat`
- `启动应用.bat`
- `data/` 文件夹
- `README.md`

**不需要包含**：
- `.venv/`（太大）
- `__pycache__/`（临时文件）
- `.git/`（版本控制）
- `packaging/`（打包失败的尝试）
