# 量化策略分析平台项目介绍 Bullet 首稿

> 用途：简历、答辩、项目展示时快速介绍项目。
> 口径：强调系统闭环、工程实现、评估与展示，不使用未经验证的收益承诺或交易承诺。

## 1. 30 秒口头版

我做的是一个基于 Streamlit 的量化策略分析平台，目标是把股票数据分析、因子计算、信号生成、参数搜索、回测评估和报告导出串成一个完整闭环。系统支持美股和 A 股数据，既可以做单股策略分析，也可以做多股组合比较；单股侧包含基础规则、因子过滤、ML 过滤、regime router 和可选新闻因子融合，多股侧支持组合模拟和权重配置。我的主要工作是把核心策略 pipeline 模块化，并把结果通过 Web 页面、模型评估页和离线 HTML 报告展示出来，让项目不仅能跑策略，也能解释策略结果和局限。

## 2. 简历 3 Bullet 版

- 构建基于 Streamlit 的量化策略分析平台，打通美股 / A 股数据加载、技术指标与 10 因子评分、交易信号生成、参数搜索、回测评估、单股工作流、多股组合模拟和 HTML 报告导出，形成从数据到展示的端到端分析闭环。
- 设计并维护模块化策略 pipeline：`core/data.py -> core/indicators.py -> core/signals.py -> core/backtest.py`，在此基础上接入 FA / ML 信号过滤、legacy / adaptive regime router、离线 `model-test` 批量研究与可选新闻因子融合，支持模型对比、分段评估和降级处理。
- 重构前端信息架构与交付材料，完成 `/strategy`、单股分析、多股分析、模型评估和最终报告等页面入口，补齐 README、架构图、因子字典、已知限制和离线 HTML 报告，使项目具备课程答辩和作品展示所需的可运行、可解释、可复现材料。

## 3. 答辩开场 1 分钟版

各位老师好，我这个项目是一个量化策略分析平台，重点不是做一个黑盒预测模型，而是把一条可解释的策略研究链路完整做出来。系统从标准化行情数据开始，先计算 RSI、MACD、EMA、ADX、ATR、布林带、OBV 等技术指标，再通过 10 个标准化因子形成综合评分，之后生成目标仓位、买卖信号，并进入回测和评估模块。

在功能上，项目分成单股和多股两条主线。单股页面可以选择或上传股票数据，调整指标窗口、因子权重、入场出场阈值和风险参数，生成策略结果、回测曲线、买卖点、Walk-Forward 验证和 HTML 报告；多股页面可以组织股票池，做价格对比、相对强弱、风险收益、因子评分、相关性分析和组合模拟。除了在线页面，我还做了 `model-test` 离线研究工作区，用来批量跑不同模型和参数组合，输出 `runs.csv`、`model_summary.csv`、`report.json`、`report.md` 等结果，再由模型评估页统一展示。

我的主要工作集中在三块：第一是把数据、指标、信号、回测、评估和组合模块拆清楚，保证核心 pipeline 可以被 UI、离线研究和导出复用；第二是加入 FA / ML 过滤、regime router、adaptive regime artifact 和可选新闻因子融合，让策略增强模块能够被比较和解释；第三是完成页面路由、结果展示、文档和报告导出，让项目从实验代码变成一个可以运行、可以讲清楚、也能说明限制的课程作品。项目结论不会表述为实盘收益承诺，而是通过回测指标、模型对比、失败记录和已知限制来说明策略在历史数据上的表现和边界。
