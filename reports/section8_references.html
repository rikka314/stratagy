8. References

This section catalogues all sources cited throughout the report. References are organised into six categories: course materials that define the project scope and methodology; data sources that supply the raw market observations; software libraries and frameworks that implement the computational pipeline; technical-analysis texts that underpin the indicator suite; machine-learning and statistical references that inform the modelling approach; and financial / quantitative-strategy references that ground the evaluation metrics and validation methodology.

8.1 Course Materials

  1. AIE1902 Lecture Notes, Lectures 3, 4, 5. Topics covered: baseline models (Naïve, Mean Reversion, Drift), technical indicators (RSI, EMA, MACD, OBV), machine-learning methods (Logistic Regression, Random Forest, XGBoost/LightGBM), Factor Analysis / PCA / ICA, and evaluation methodology (walk-forward validation, risk-adjusted metrics).
  2. AIE1902 Project Guidelines, Version 4. Requirements specification for the quantitative strategy analysis project, including deliverable structure, model requirements, baseline comparison criteria, and grading rubric.

8.2 Data Sources

  1. AkShare — Open-source financial data interface library for the Chinese and U.S. equity markets, providing OHLCV (Open, High, Low, Close, Volume) historical price data. Available at: https://github.com/akfamily/akshare.
  2. Yahoo Finance (accessed via AkShare). Primary data source for U.S. equity historical price data used in this project.

8.4 Technical Analysis References

  1. Wilder, J.W. (1978). New Concepts in Technical Trading Systems. Greensboro, NC: Trend Research. Foundational reference for the Relative Strength Index (RSI), Average True Range (ATR), and Average Directional Index (ADX) indicators used in the signal-generation layer.
  2. Appel, G. (2005). Technical Analysis: Power Tools for Active Investors. Upper Saddle River, NJ: FT Press. Primary reference for the Moving Average Convergence Divergence (MACD) indicator and its signal-line crossover logic.
  3. Bollinger, J. (2001). Bollinger on Bollinger Bands. New York: McGraw-Hill. Reference for the Bollinger Bands volatility envelope used as a regime-awareness and mean-reversion signal component.
  4. Granville, J. (1963). Granville’s New Key to Stock Market Profits. Englewood Cliffs, NJ: Prentice-Hall. Original formulation of the On-Balance Volume (OBV) indicator, which serves as the volume-confirmation factor in the scoring model.

8.5 Machine Learning and Statistical References

  1. Hamilton, J.D. (1989). “A New Approach to the Economic Analysis of Nonstationary Time Series and the Business Cycle.” Econometrica, 57(2), 357–384. Foundational work on Markov regime-switching models, which informs the adaptive regime detection and routing logic in core/adaptive_regime.py.
  2. Haykin, S. (2009). Neural Networks and Learning Machines, 3rd ed. Upper Saddle River, NJ: Pearson. Reference for the mathematical foundations of Factor Analysis, used in the factor-extraction and dimensionality-reduction stages of the pipeline.

8.6 Financial and Quantitative Strategy References

  1. Sharpe, W.F. (1966). “Mutual Fund Performance.” Journal of Business, 39(1), 119–138. Original derivation of the Sharpe Ratio, which is the primary risk-adjusted return metric used throughout the evaluation framework.
  2. Fama, E.F. (1970). “Efficient Capital Markets: A Review of Theory and Empirical Work.” Journal of Finance, 25(2), 383–417. Seminal paper on the Efficient Market Hypothesis (EMH), providing the theoretical backdrop against which active strategy alpha is measured.
  3. López de Prado, M. (2018). Advances in Financial Machine Learning. Hoboken, NJ: Wiley. Key reference for walk-forward validation methodology, combinatorial purged cross-validation, and overfitting detection techniques applied in the parameter-learning and model-checking sections.
